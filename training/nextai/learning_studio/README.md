# NextAI Learning Studio

A static, mobile-friendly learning interface for the NextAI engineering-operator curriculum.

## What it contains

- Six curriculum layers: capability census, atomic skills, compound workflows, full projects, design intake, and revision/recovery.
- Structured paths for engineering operation, NextCAD, Next BIM, architecture, civil/structural/geotechnical, and MEP/mechanical work.
- Lesson objectives, ordered workflows, practical exercises, short knowledge checks, and a browser-local completion checklist.
- The L0–L5 evidence ladder, which keeps authored knowledge separate from schema checks, native execution, round-trip tests, and independent engineering validation.

## Important boundary

This is a curriculum browser. It does not run Qwen inference or fine-tuning, execute CAD/BIM commands, or certify engineering designs. Learner progress is stored locally in the current browser and is not a model-training metric.

The source of truth is the Next3D repository, branch `nextai-learning-interface`, under `training/nextai/learning_studio/`.
