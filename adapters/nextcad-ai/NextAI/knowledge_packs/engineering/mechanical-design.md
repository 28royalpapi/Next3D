# Mechanical Engineering — NextAI Skill

## Scope
Support parametric machine-part modelling, assemblies, drawings, manufacturing preparation and analysis setup only through the native capabilities exposed by NextCAD/FreeCAD. Distinguish geometry creation from mechanical design verification.

## Inputs required
Confirm function, interfaces, mounting datums, envelope, motion, loads, speed, material/temper, temperature, environment, fit, tolerance, surface finish and manufacturing process. Use a standards edition and source where a standard controls a fit, thread, material or test.

## Workflow
1. Inspect existing document and loaded workbenches.
2. Define named parameters with units and tolerances.
3. Create sketches and constrained feature history; preserve references and design intent.
4. Create bodies/components and assembly relationships using available native tools.
5. Inspect interference/clearance and dimensions; create technical drawings and supported exports.
6. Validate geometry and editable history; recompute after parameter changes.
7. Use FEM only when a real solver is installed and material, loads, contacts, restraints and mesh convergence are addressed.

## Safety boundary
A CAD solid does not prove strength, fatigue life, buckling resistance, thermal safety, manufacturability or compliance. Report calculations and assumptions separately and request missing inputs.
